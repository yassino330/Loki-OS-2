# LokiOS Beta — release notes

## Status
LokiOS beta is an early testing release, not a stable operating system. It is intended for virtual machines and testers who can recover their computers if something goes wrong.

## Included
- Linux 6.12.y kernel, pinned to an exact upstream source revision for each build.
- Debian Trixie live userspace with systemd.
- LokiOS Qt Quick desktop shell and welcome screen.
- Chromium browser.
- Graphical live session and experimental UEFI installer.
- ISO artifact and SHA-256 checksum generated by CI.

## Known limitations
- The live userspace is Debian-based; LokiOS is not yet an independent distribution.
- Desktop controls and settings are still prototype quality.
- The installer currently supports UEFI/GPT and erases the selected target disk. Test only on a disposable virtual disk until independently validated.
- Hardware compatibility varies. Wi-Fi, graphics, audio, suspend, and power management are not validated across a broad device matrix.
- No guarantee of data preservation, reliability, or suitability for daily use.

## Before installing
1. Prefer QEMU/VirtualBox/VMware and create a disposable virtual disk.
2. Verify the downloaded ISO with the accompanying SHA-256 file.
3. Boot the live desktop and check display, keyboard, mouse, networking, and Chromium.
4. If testing the installer, select only the disposable virtual disk. The installer repartitions and formats the selected disk.
5. Confirm the installed system boots after detaching the ISO.

## Reporting bugs
Include the beta tag, computer/VM details, firmware mode (UEFI/BIOS), exact reproduction steps, and relevant logs. Never include passwords, access tokens, or private data.
